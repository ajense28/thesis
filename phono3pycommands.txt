for dftb+ {
    Once all your DFTB+ jobs are finished, please follow these steps:
Open the FORCE_SET-fromDFTB+ script and update the "atoms" value based on the number of atoms in your supercell (from POSCAR-001, not your original unit cell).
For example, if your unit cell has 8 atoms and you\'re using a 2×2×1 supercell, your POSCAR-001 (and the other files) will contain 8 × 2 × 2 = 32 atoms. In that case, set atoms = 32 in the script.
Run the following command:
./FORCE_SET-fromDFTB+ phono3py_disp.yaml 259380 detailed.out
Here, 259380 is the number of displacement structures (i.e., POSCAR files) generated by PHONO3PY.
This command will generate the FORCE_SET-DFTB file.
For the final step, apply the unit conversion using:
perl -pe 's/\b(\d+\.)?\d+\b/$&*51.422060474863656/ge' FORCE_SET-DFTB > FORCES_FC3
(I don’t recall the exact reason for the conversion factor, but it’s a required step to match the expected units.)
You can now use the generated FORCES_FC3 file for your calculations.
Let me know if you have any questions!
}

from phono3py wiki, command list:
phono3py forces postprocess
generate FORCES_FC3 from vasp outputs
phono3py --cf3 disp-{001..NNN}/vasprun.xml
generate FORCE_SETS from FORCES_FC3
phono3py --cfs
generate FORCES_FC2 from FORCE_SETS
phono3py --fs2f2
create fc2.hdf and fc3.hdf from FORCES_*
phono3py --fc-symmetry
calculate thermal conductivity
phono3py --mesh x x x --br
to find irreducible q-points to file ir_grid_points.yaml
phono3py --fc3 --fc2 --mesh n n n --br --wgp
to output these grid points
grep grid_point: ir_grid_points.yaml|awk '{printf("%d ", $3)}'
to get phonon lifetimes on specified points (--gp)
phono3py --mesh 11 11 11 --br --write-gamma --gp 0 1 2 3 4 5 12 13 
(see https://phonopy.github.io/phono3py/workload-distribution.html#workload-distribution)
after calculating at all irreducible grid points, to get gamma
phono3py-load --mesh 11 11 11 --br --read-gamma
after these calculations run without problems, the hdf5 files on grid points can be discarded

phono3py-load --config mesh.conf [options]
